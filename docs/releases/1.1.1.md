# quiby.core — 1.1.1

Лаунчер и API **1.1.1**, сборка Minecraft **6.1.25**, игровой мод **Quiby 1.1.18**.

- Свой экран перезапуска: ожидание возвращения сервера и автоматическое подключение.
- Убрана чёрная вспышка перед паузой; фон мира остаётся размытым.
- Исправлено зависание ПКМ, когда переносимый игрок выходит из рэгдолла.
- Enter отправляет сообщение, не переключая локальный и глобальный каналы.
- Сообщения Discord отмечены ярко-синим «Д», а «Фото ↗» открывается внутри игры.
- «Моды» доступны в главном меню и меню паузы.
- Автоматический direct: лаунчер сравнивает задержку и разброс пяти замеров,
  выбирает более стабильный быстрый маршрут и сохраняет обычное подключение
  при отсутствии выигрыша. Закрытие окна лаунчера не обрывает туннель игры.

Minecraft **1.21.1**, NeoForge **21.1.250**. Голосовой UDP не менялся.
Результат direct зависит от сети игрока; снижение пинга не гарантируется.
Установщик Windows пока без цифровой подписи.
