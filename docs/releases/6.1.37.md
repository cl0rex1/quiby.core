# Quiby 6.1.37 / quiby.mod 1.1.30

Исправлена отсутствующая музыка открытия. В предыдущем OGG первым находился видеопоток обложки Theora: штатный декодер Minecraft завершался ошибкой `Invalid Ogg identification packet`. Теперь в файле только Vorbis, 48 кГц, stereo, 14,88 секунды.

Проверки: старый файл воспроизводимо отклонён JOrbis; исправленный полностью декодирован с ненулевым PCM. В настоящем клиенте серверная команда создала четыре аудиобуфера OpenAL, источник находился в AL_PLAYING с положительной громкостью и продвигался во времени при MUSIC=0 и RECORDS=0. Проверка декодирования входит в `gradlew build`.

После обновления сборки полностью закройте и снова запустите Minecraft. Операторская команда `/quiby opening music` проверяет трек без запуска церемонии; `/quiby opening music stop` останавливает его. Музыка церемонии по-прежнему запускается при оставшихся 12 секундах отсчёта.

Лаунчер и API остаются 1.1.5. Исправленный клиент совместим с сервером quiby.mod 1.1.29: меняется клиентский аудиоресурс, перезапуск рабочего сервера не требуется.
