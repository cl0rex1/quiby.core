# Обновление Minecraft-сервера до 6.1.10 (тестовая)

Для Minecraft 1.21.1 / NeoForge 21.1.250. Это обновление существующего сервера.
API, Docker и Cloudflare обновлять не требуется.

1. Остановите Minecraft-сервер. Сделайте резервную копию мира, mods и конфигов.
2. Переместите старые quiby-*.jar и offbalance-*.jar из mods в резервную папку вне mods.
   Если остались Ragdoll Revival, Reactions или Corpse, также уберите их.
3. Скопируйте два JAR из mods архива: Quiby 1.1.8 и Off Balance 2.0.
   Sable и Sable Player Ragdoll 0.7.5 оставьте установленными.
4. В config/offbalance-server.toml измените следующие ключи в соответствующих секциях,
   сохранив остальные настройки. Если конфиг отсутствует, используйте шаблон архива.
5. Если существует <level-name>/serverconfig/offbalance-server.toml, измените те же ключи
   и в нём. level-name указан в server.properties. defaultconfigs — шаблон для новых миров.

```toml
[balance]
balanceEnabled = false

[hurtProxy]
hurtProxyEnabled = false

[manualDismount]
dismountRequireGrounded = true
dismountMaxSpeed = 1.0
dismountMaxSpin = 1.5
dismountHoldTicks = 10
```

6. Запустите сервер. Игрокам нужно обновить сборку до 6.1.10 через лаунчер.

Quiby записывает позицию offline-тела раз в секунду и уточняет её перед входом игрока.
Для выгруженного тела используется последняя сохранённая позиция. Инвентарь и удаление
тела обслуживает Off Balance. Для старого тела, которое ещё не загружалось с новым модом,
может сохраниться прежняя координата выхода.

Сборка и проверки координат прошли. Сетевой сценарий ещё требует проверки: один игрок
выходит, другой перемещает тело, первый возвращается рядом с телом; инвентарь возвращается
один раз, тело удаляется. Повторите после перезапуска и выгрузки чанка.

Для отката остановите сервер и восстановите весь комплект резервной копии, включая мир.
