# Обновление Minecraft-сервера до сборки 6.1.7

Это дополнение к существующему Minecraft 1.21.1 / NeoForge 21.1.250 серверу, а не полный сервер. Docker API и Cloudflare Tunnel для этих игровых изменений обновлять не требуется.

1. Остановите Minecraft-сервер и сохраните резервную копию мира, `mods` и конфигов.
2. Уберите из серверной папки `mods` старый `quiby-*.jar`, `ragdoll_corpse-*.jar`, `ragdoll_reactions-*.jar`, `sable_ragdoll_revival-*.jar`. Переместите их в резервную папку **вне** `mods`.
3. Скопируйте оба JAR из `mods` этого архива в серверную папку `mods`: Quiby 1.1.5 и Off Balance 2.0. Базовый Sable Player Ragdoll 0.7.5 оставьте.
4. В `config/offbalance-server.toml` задайте `balanceEnabled = false` в секции `[balance]`. Если файла ещё нет, скопируйте его из папки `config` архива. Остальные настройки существующего файла сохраните. На NeoForge 21.1.250 этот путь подтверждён тестовым запуском.
5. Если у мира уже есть `<level-name>/serverconfig/offbalance-server.toml`, выставьте там тот же параметр: настройки мира могут переопределять общие. Имя мира — `level-name` в `server.properties`. В архиве также есть шаблон `defaultconfigs/offbalance-server.toml` для установок, использующих эту папку.
6. Запустите сервер и проверьте журнал на ошибки. Игроки должны обновить сборку через лаунчер.

Quiby создаёт `config/quiby-server.toml` с включёнными `ragdoll.onDamage` и `ragdoll.onExplosion`. Активное тело не перезапускается; творческий режим и наблюдатель исключены. Не возвращайте старый Ragdoll Reactions: реакции теперь реализованы в Quiby.

Проверьте с тестером: урон в выживании, взрыв рядом и за стеной, восстановление после падения, преследование мобами и скин тела. Off Balance содержит собственную обработку тел и восстановления, поэтому Corpse и Revival удалены.

Для отката остановите сервер и восстановите **весь комплект** из резервной копии (моды, конфиги и мир). Не смешивайте версии серверной и клиентской сборки.
