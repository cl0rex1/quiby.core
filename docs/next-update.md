# Следующее обновление: перезапуск, чат и автоматический маршрут

Изменения выпущены в лаунчере/API 1.1.1, сборке 6.1.25 и Quiby 1.1.18.
Сведения об установке и откате: [deployment-1.1.1.md](releases/deployment-1.1.1.md).

## Minecraft / quiby.mod

- Объявленный перезапуск открывает экран ожидания в стиле Quiby. Клиент
  учитывает время возвращения сервера, проверяет его Minecraft status в фоне
  и подключается снова. Можно вернуться в меню. Отказ авторизации или бан
  остаётся обычным сообщением об отключении.
- Убрана чёрная вступительная заливка паузы; сохраняется размытие мира.
- Захват рэгдолла проверяет существование движущегося тела, включая случай,
  когда служебный блок ещё не удалён. Исчезнувший объект освобождает ПКМ
  и серверное состояние. Защита от столкновения с обычным брошенным телом
  сохранена.
- Enter в чате возвращает фокус строке ввода. Кнопка канала переключается
  мышью, а не перехватывает отправку сообщения.
- Сообщения Discord имеют ярко-синий префикс «Д». Ссылка «Фото ↗» открывает
  клиентский просмотр вместо отправки служебной команды на сервер.
- «Моды» доступны из главного меню и паузы.

## Лаунчер / API

Автоматический frp-туннель запускается вместе с игрой. Лаунчер сравнивает
пять замеров каждого маршрута и учитывает медиану и разброс. При отсутствии
выигрыша используется обычный публичный адрес. Закрытие окна лаунчера
не обрывает игру: транспорт работает в фоне и завершается вместе с Minecraft.

API выдаёт отдельный билет разрешённому Discord-аккаунту и повторно проверяет
его доступ на heartbeat. Публикация прокси разрешена только домашнему provider.
TLS-сертификат, архив и исполняемый файл проверяются. Служебные ключи остаются
на сервере. Подготовка постоянных служб описана в
[deploy/direct/README.md](../deploy/direct/README.md).

Для включения при выпуске нужны новый API с `DIRECT_*`, две постоянные службы
на VPS и домашнем сервере, новый лаунчер и quiby.mod. Без настройки API direct
выключен, обычное подключение сохраняется. Внешний маршрут Киров → Астана
не подтверждён локальными тестами: после развёртывания нужен повторный замер
с компьютера игрока. Голосовой UDP это обновление не меняет.

## Проверки

- TypeScript typecheck и сборка рабочих пространств.
- 75 тестов Node.js прошли, один существующий тест пропущен.
- Реальные frpc/frps: TLS, передача данных, отказ анонимному и legacy visitor,
  запуск транспорта лаунчером и очистка приватной конфигурации.
- Electron: собранный renderer, preload, настройки и IPC.
- Minecraft client: Enter, список модов и возврат в паузу, исчезнувший захват
  при удерживаемой ПКМ, открытие фото по ссылке, fit/zoom/pan/reset/close,
  ping/pong, экран перезапуска, status probe и сохранение отказа авторизации.
- Dedicated Minecraft: исправление скина, действующий grab target и удалённый
  sublevel с ещё существующим блоком рэгдолла.
