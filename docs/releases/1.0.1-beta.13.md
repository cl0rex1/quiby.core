# quiby.core Тестовый 1.0.1-beta.13

- Перед запуском проверяются реальные JAR и ZIP в mods/resourcepacks, а не только список интерфейса.
- Файлы сборки сверяются по SHA-256. Сторонние моды требуют ручного одобрения точного хеша через существующий вайтлист; наличие в Modrinth само по себе недостаточно.
- Сторонние ресурспаки и распакованные папки блокируют запуск. Передайте пак администрации для проверки и добавления в сборку. Пользовательские файлы проверка не удаляет.
- Проверяются ссылки на другие папки, отсутствующие и подменённые файлы. Причина отказа показывается пользователю.
- Сборка 6.1.16 снижает минимальную задержку ручного выхода из ragdoll до 1 секунды; серверный конфиг Sable нужно обновить отдельно.

Это контроль допуска файлов при штатном запуске. Он не является серверной проверкой движения/боёв или защитой от изменённого лаунчера, стороннего клиента и изменений файлов во время игры. Для этого нужен отдельный серверный контроль.

Пользователям необходимо установить beta.13. Старые лаунчеры не получают новые проверки через обновление одной сборки. API совместим с существующим вайтлистом и не требует обновления.
