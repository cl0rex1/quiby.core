# quiby.core Тестовый 1.0.1-beta.14

- Автопроверка пользовательских JAR: метаданные, описания, пути, классы и вложенные архивы. Файлы без найденных признаков допускаются автоматически; подозрительные требуют рассмотрения. Запрет администрации имеет приоритет.
- К заявке прикрепляется сам JAR. Большие файлы доступны через кнопку скачивания в боте.
- Статусы модов обновляются автоматически каждые 20 секунд и при возвращении в окно. Решения появляются в уведомлениях, удалять и добавлять мод заново не нужно.
- Администрация может изменить решение. Старую заявку можно открыть командой /mod-review id.
- Исправлено наложение верхнего блока обновления на сайдбар.

Автопроверка является эвристикой, а не гарантией отсутствия читов. Контроль официальных файлов и ресурспаков по манифесту сохранён.

Для работы заявок с файлами и пересмотра решений обновите API quiby.core и quiby.bot. Minecraft-сервер и сборка 6.1.16 в этом выпуске не меняются. Для старых заявок, чей JAR раньше не сохранялся, файл потребуется выбрать один раз повторно.
