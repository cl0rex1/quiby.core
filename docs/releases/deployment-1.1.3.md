# Развёртывание 1.1.3 / 6.1.29 — 22 октября 2026

Опубликованы Windows-лаунчер 1.1.3 и сборка 6.1.29 с Quiby 1.1.22. Публичные latest/beta-метаданные установщика, размеры и SHA-256 активов проверены; манифест содержит 178 проверенных путей/хэшей/размеров. Фактическая версия mods.toml теперь 1.1.22.

API собран поверх прежнего образа 1.1.2, проверен в отдельном контейнере без сети и развёрнут как `quiby-core-api:1.1.3`. Существующие переменные окружения, ключи, данные и исключения доступа сохранены. Текущая обязательная версия лаунчера — 1.1.3; 1.1.2 отклоняется с HTTP 426.

Рабочий Minecraft обновлён через `quiby restart 60`, с сохранением мира и резервной копией `/crafty/backups/quiby-pre-629-20261022T103203Z.tar.gz`. Новый JVM PID 1161 открыл `quiby-1.21.1-1.1.22.jar`, подтвердил готовность новым latest.log; проверены SHA-256 всех 37 JAR. Серверный ZIP: `688164f7b341a3336fe6cbec85c0f32727180a81a42e284a47605f08c13d1839`. Сборка 6.1.29 активирована в API после проверки JVM. Церемония на рабочем сервере не запускалась.

У direct-провайдера удалён унаследованный healthcheck HTTP API на 3001: он ошибочно помечал исправный frpc как unhealthy. Контейнер пересоздан с теми же образом, командами, пользователем, файлами авторизации, host network, read-only rootfs, лимитами и ограничениями; прежний контейнер сохранён остановленным как `quiby-direct-provider-pre-113`. До исправления наблюдались единичные таймауты STUN. Новый клиент даёт повторным попыткам интервал 5 секунд и окно до 35 секунд.

После обновления настоящий авторизованный visitor установил direct в домашней LAN: медиана полного Minecraft status/ping/pong около 9 мс против 241 мс через обычный маршрут. Это сравнение включает установление TCP и запрос статуса; его нельзя приравнивать к числу в игровом Tab. Выигрыш для внешних игроков из этой проверки не следует. Устройство NAT может не допустить XTCP; тогда остаётся обычное подключение. Принципы и ограничения: [официальная документация XTCP](https://gofrp.org/en/docs/features/xtcp/).

Публичный голосовой UDP `play.quiby.me:24454` после обновления дал три корректных ответа по nonce, примерно 78–87 мс. Его Docker-порт и WireGuard-маршрут сохранены.

Проверки перед выпуском: Gradle build и проверки мода; отдельный dedicated server с реальными CBC/Sable (граница, режимы, эффекты, отмена, защита, безопасные снаряды и фейерверки); настоящий клиент (мышь/клавиатура, Enter/!, синхронизация Г/Л, прозрачность, меню, фото, полёт CBC и статус сервера); TypeScript-проверки; 75 Node-тестов пройдены, один пропущен; отдельный тест с настоящими frps/frpc и авторизацией пройден; пять проверок серверного пакета пройдены.

Arch-пакет `apps/launcher/release/linux/quiby-core-1.1.3-1-x86_64.pkg.tar.zst` создан и проверен локально. Linux-артефакты не публиковались.

Общая блокировка лаунчера остаётся **включённой**, как было задано в админке до этого выпуска. Исключения и индивидуальные ограничения не менялись.
