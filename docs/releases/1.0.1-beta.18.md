# quiby.core Тестовый 1.0.1-beta.18

- Добавлена вкладка Ресурспаки: импорт ZIP, отправка заявки с файлом в Discord, обновление решения каждые 20 секунд и уведомления при изменении статуса, открытие папки и корзина.
- Проверка ресурспаков работает внутри Minecraft при обновлении списка и перезагрузке ресурсов. Неодобренные и изменённые ZIP не доступны для выбора; допуск основан на хеше, а не имени файла. Новое одобрение применяется после перезапуска игры.
- Убрана кнопка К лаунчеру до входа. Гость не может менять скин аккаунта; отложенная отправка скина отменяется после выхода.
- Добавлены фильтры Графика, Геймплей, Библиотека, Лаунчер и Мод. Aeronautics использует общий тег Механика.
- Исправлены ссылки и логотипы Mouse Tweaks, REI, ReJei, Curios API, Create Diesel Generators, Explosion Overhaul, Off Balance, Packet Fixer, Sable Ragdolls Patch и модов Quiby. Логотипы этих модов включены в приложение.
- Выделение скриншотов, шейдеров и схематик приведено к общей панели действий; доступны выбор всех, снятие выбора и групповая корзина, копирование скриншота. В галерее работают Ctrl/Cmd и Shift.
- Файлы можно импортировать в любой точке открытой вкладки; подсказка появляется только при перетаскивании. Декоративные логотипы больше нельзя случайно утащить на рабочий стол.
- Скины в коллекции можно подписывать (до 24 символов); убрана кнопка удаления под предпросмотром.
- Кнопки подтверждения выбора сборки и настройки памяти закреплены и остаются доступными при прокрутке.

Требуются сборка 6.1.17 (quiby.mod 1.1.12) и актуальный API. Discord-вложения сохраняют лимит 8 МиБ. Обновление Minecraft-сервера для этого клиентского фильтра не требуется; API на домашнем сервере обновляется отдельно. Вход через Discord OAuth. Установщик Windows пока не подписан.
