# quiby.core 1.1.4

- Проверенный frpc 0.71.1 включён в Windows-установщик вместе с лицензией Apache 2.0 и сведениями об исходниках. Direct больше не требует отдельной загрузки с GitHub на компьютере игрока. SHA-256 проверяется при сборке и перед запуском; повреждённый старый кэш не подменяет встроенный файл.
- Ошибки direct сохраняют конкретный этап (бинарный файл, каталог сессии, локальный порт, конфигурация, запуск процесса), код Windows и сообщение ошибки. Билеты входа из сообщений удаляются. Ошибки запуска процесса и открытия порта корректно обрабатываются.
- Неудачная подготовка direct оставляет обычное подключение доступным. Настройки безопасности, проверка сертификата и проверка доступа игрока сохранены.

Сборка Minecraft остаётся **6.1.34**, quiby.mod **1.1.27**. Этот выпуск исправляет подготовку транспорта; успех соединения через NAT у конкретного игрока подтверждается новым `direct/latest-route.json` после запуска.

Windows-установщик публикуется. Linux/Arch остаётся локальным пакетом; direct на Linux пока не включён.
