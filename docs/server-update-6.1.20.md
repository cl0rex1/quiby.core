# Серверное обновление 6.1.20

Quiby обновлён до 1.1.15. Добавлены семь отсутствующих рецептов Create Radars 3.0.0,
исправлены переводы названий модов и включена цепная детонация разрывных снарядов CBC.
Create Radars остаётся 5.0-EA-3.0.0-1.21.1, CBC — 5.11.7+mc.1.21.1.

Остановите сервер и сохраните резервную копию мира. Замените прежний игровой
Quiby JAR на `quiby-1.21.1-1.1.15.jar`; не оставляйте несколько версий. Если
обновляете более старую сборку, также замените Radars и Off Balance файлами
из архива. Существующие настройки переносите с сохранением своих значений.
Клиентский `quiby-early-loading` на dedicated server не устанавливается.

Quiby создаёт `quiby-projectiles-server.toml`: enabled=true,
requireExposure=true, detonationsPerTick=64, maxBlastRadius=32.
В NeoForge серверные настройки могут находиться в `config` или `serverconfig`
мира в зависимости от конфигурации сервера. Лимит очереди — 4096 снарядов;
цепные волны переносятся на следующие тики. Укрытия защищают от подрыва.

Проверено на изолированном сервере: все семь рецептов загружаются, HE и flak
детонируют штатным способом ровно один раз, цепная реакция распространяется
в воздухе; болванки, дальние и закрытые сплошным укрытием снаряды исключены.

Для фоновых заявок и рассылок beta.23 обновите также API из соответствующего
коммита quiby.core. Миграция SQLite добавляет поля новостей и индекс заявок
при запуске. Перед обновлением сохраните резервную копию базы и хранилища.
Рассылки доступны в `/admin/` → «Новости и рассылки» и `POST /api/admin/news`.
