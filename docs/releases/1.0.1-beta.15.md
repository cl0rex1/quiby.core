# quiby.core Тестовый 1.0.1-beta.15

- Заявка отправляется вместе с JAR. Бот публикует файл вложением Discord; новые JAR не записываются на диск API.
- Передача через ограниченную очередь в памяти, максимум 10 минут. После подтверждения доставки буфер освобождается. Лимит вложения — 8 МиБ.
- Лаунчер показывает успех после подтверждения бота. Если бот недоступен или очередь потеряна при перезапуске API, отправку можно повторить без дубликата ожидающей заявки.
- Добавлена блокировка Gamma Utils и признаков gamma/fullbright в метаданных, путях и содержимом JAR, включая вложенные архивы и переименованные файлы. Обнаруженный запрет не отменяется прежним одобрением вайтлиста.

Проверка по признакам не гарантирует обнаружения произвольного обфусцированного кода.

Для нового способа отправки обновите API quiby.core и quiby.bot вместе с лаунчером. Старые сохранённые JAR из каталога mod-reviews удаляются при старте обновлённого API. Для недоставленных старых заявок файл потребуется отправить повторно.

Minecraft-сервер и опубликованная сборка 6.1.16 не меняются. Эксперимент с dismountRequireGrounded в этот выпуск сборки не включён.
