# Серверное обновление 6.1.24

Minecraft 1.21.1 / NeoForge 21.1.250 / Quiby 1.1.17. Нужны согласованные API
и лаунчер 1.1.0, бот 0.0.7. Состав сторонних модов сохранён от 6.1.22/6.1.23.

Сначала сделайте резервную копию мира, конфигов и старого серверного Quiby.
При остановленном сервере замените прежний `mods/quiby-*.jar` новым
`quiby-1.21.1-1.1.17.jar`, оставив единственную основную версию Quiby.
Клиентский `quiby-early-loading` на сервер не переносится.

Полный `quiby-server-6.1.24.zip` содержит start.sh с ожиданием окна перезапуска,
restart_wait.py и безопасное объединение конфигов prepare.py. Для Crafty
используйте restart_wait.py перед JVM и включите штатный автоматический повтор
запуска. Не заменяйте существующий мир или server.properties шаблоном.

Запрошенные перезапуски включены в `quiby-community-server.toml`:
06:59 по Астане с запуском не раньше 07:01, вечером 20:00. До установки
перезапускающего supervisor используйте `scheduledRestarts=false`.

Для Discord-моста одинаковый отдельный GAME_BRIDGE_API_KEY задаётся API и
Minecraft, GAME_BRIDGE_API_URL указывает на https://api.quiby.me. Боту нужны
MOD_REVIEW_API_URL, существующий MOD_REVIEW_BOT_API_KEY и MINECRAFT_CHAT_ENABLED=true.
Без ключей мост выключен. Ключи и пользовательские данные в архивы не входят.

Изменения: восстановление скина туловища, освобождение ПКМ, безопасная позиция
возврата, урон от меньших падений, onbar, `/ping`, чат и переводы. Команды:
`/ping` — переключить живой замер; `/quiby notice текст` — объявление;
`/quiby restart 60` — перезапуск через минуту; `/quiby restart cancel` — отмена.
Объявления и перезапуски требуют уровень оператора 2.
