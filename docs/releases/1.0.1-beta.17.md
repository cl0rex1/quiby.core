# quiby.core Тестовый 1.0.1-beta.17

- Неразрешённые пользовательские моды автоматически появляются в административной панели: игрок, имя файла, SHA-1, размер и причина проверки.
- Повторные проверки не создают дубли и не сбрасывают решение администратора. Автоматические записи не отправляются в очередь Discord-бота.
- Ручное одобрение применяется к конкретному SHA-1, включая моды, заблокированные автоматическими правилами.
- Добавлены исключения для JAR больше 100 МБ, до 512 МБ: запуск возможен только после ручного одобрения файла. Полная автоматическая распаковка больших JAR не выполняется.
- Веб-панель также принимает JAR до 512 МБ для локального определения данных файла.

Требуется актуальный API quiby.core. Minecraft-сервер и сборку модов обновлять не нужно.
