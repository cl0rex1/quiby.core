# quiby.core 1.0.1-beta.25

- Исправлено повторное появление уведомлений о проверке после очистки почты и перезапуска лаунчера. Изменение формулировки того же статуса больше не возвращает удалённую карточку; новое решение по актуальному файлу по-прежнему приходит.

- Исправлены размеры и выравнивание иконок ресурспаков и шейдеров.

Проверки: сборка Windows x64, TypeScript, 7 UI-тестов и 3 теста уведомлений.

Windows-установщик предварительного канала не подписан.
