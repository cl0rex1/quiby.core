# quiby.core Тестовый 1.0.1-beta.21

Совместное обновление со сборкой Minecraft 6.1.18 и quiby.mod 1.1.13.

- Лаунчер получает игровой билет после Discord-входа и создаёт временный ключ Ed25519 для проверки подключения к серверу.
- Сервер проверяет актуальный доступ аккаунта, ник, UUID и подпись запроса до появления игрока в мире. Discord-токен в Minecraft не передаётся.
- Исправлен возврат к offline-рэгдоллу на выделенном сервере.
- Индекс Explosion Overhaul загружается или создаётся автоматически без клиентского окна.
- Опубликована полная серверная сборка: 36 JAR, Java 21 / NeoForge 21.1.250, конфиги и запуск для Ubuntu/CasaOS. 18 клиентских или ненужных серверу JAR исключены.

Для нового серверного входа нужны обновлённые API, лаунчер и клиентский Quiby. Старый клиент сервером отклоняется. Проверка подтверждает аккаунт, но не неизменность клиентского приложения.

Проверены сборки API и лаунчера, типы, 47 успешных тестов проекта (один пропуск), сборка и проверки Java-мода, конфиги и запуск dedicated server на Java 21 до Done со штатной остановкой. Вход реального игрока и Linux/Docker требуют проверки после установки.

Windows x64, NSIS-установщик. Тестовая версия; установщик не подписан.
