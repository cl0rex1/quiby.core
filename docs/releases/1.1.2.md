# quiby.core 1.1.2

- Direct получает время на установку соединения через NAT, затем сравнивает пять замеров. Выбранный маршрут и замеры сохраняются в диагностике без билетов и ключей.
- Сборка 6.1.28: исправлены ПКМ после захвата рэгдолла и чёрные жидкости в REI, сглажен логотип сезона.
- quiby.mod проверяет запуск через лаунчер. «Винланс свет» скрыт из творческого инвентаря и REI, пустая вкладка Explosion Overhaul убрана.
- Добавлены команды церемонии открытия у костра: подготовка, отдельный запуск, отмена и статус. Эффекты без урона и разрушений.
- Настроен маршрут Simple Voice Chat: отдельный UDP 24454 через VPS и явный адрес голосового сервера, работающий также при direct-подключении. Проверен ответ голосового сервера через публичный адрес.

Minecraft 1.21.1 / NeoForge 21.1.250. Quiby 1.1.21. Установщик Windows опубликован; пакет Arch Linux подготовлен отдельно и не публикуется.
