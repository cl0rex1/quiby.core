## Что выпущено

Экран ожидания объявленного перезапуска с проверкой готовности и повторным
подключением; устранение чёрной вспышки паузы; очистка зависшего захвата
рэгдолла; исправление Enter в чате; синий префикс «Д» для Discord;
клиентский просмотр «Фото ↗»; кнопка «Моды» в главном меню и паузе.

Лаунчер запускает проверенный frpc 0.71.1 вместе с Minecraft. Пять настоящих
Minecraft ping/pong на маршрут, медиана и разброс определяют выбор соединения.
При недостаточном выигрыше остаётся обычный публичный маршрут. Транспорт
живёт до завершения игры, включая закрытие окна лаунчера. Голосовой UDP
этим выпуском не меняется.

## Проверки

- TypeScript, сборки рабочих пространств, Gradle и регрессионные проверки.
- Node: 75 успешных тестов, один существующий пропуск.
- Настоящий Electron: renderer/preload/IPC; настоящий Minecraft-клиент:
  пауза, меню модов, ввод чата, просмотр фото, ожидание рестарта и отказ входа.
- Dedicated server: профиль рэгдолла и освобождение захвата, в том числе
  при удалённом движущемся подуровне и оставшемся служебном блоке.
- Опубликованные установщик и оба канала автообновления проверены по хешам;
  все 178 файлов клиентского манифеста проверены по пути, размеру и SHA256.
- Живой API: версия, ограничение версий лаунчера, манифест сборки,
  защита моста и точное совпадение опубликованного скрипта админки.
- Рабочий Minecraft: все 37 серверных модов совпадают с lock-файлом 6.1.25.
- Московский координатор: TLS и авторизация provider подтверждены; рабочий
  API выдал билет разрешённому аккаунту, frpc получил настоящий Minecraft
  status и совпадающий pong. Пробные процессы и конфиги удалены.

Проба с домашней машины дала STCP 267.8/264.1/266.7 мс и адаптивный маршрут
6.7/6.9/6.8 мс. Это проверка работоспособности инфраструктуры из домашней
сети, а не доказательство выигрыша у внешнего игрока. Для Кирова нужен
замер с компьютера игрока; лаунчер самостоятельно оставит лучший маршрут.

## Постоянные службы

На домашнем сервере `quiby-direct-provider` работает как контейнер Docker
с `restart: unless-stopped`, host network, read-only root, без capabilities,
с лимитом памяти 128 MiB. Приватные файлы находятся в
`/home/cl0rex1/quiby-releases/1.1.1/direct-home`.

На VPS `185.146.157.76` включена systemd-служба `quiby-direct-coordinator`;
файлы находятся в `/opt/quiby-direct-coordinator`, порт 443/TCP.
HTTP-plugin обращается к `https://api.quiby.me/api/direct/authorize`.
TLS обязателен; сертификат закреплён в клиенте, срок 730 дней.
Перед его истечением нужно согласованно обновить сертификат сервера и CA API.
Посетители допускаются только как `quiby-player`, provider публикует только
два игровых прокси. Общего постоянного ключа посетителей в лаунчере нет.

Обычные HAProxy/WireGuard и публичный порт 25565 сохранены. Прежняя тестовая
служба и её таймер остановлены. Временные HTTPS-серверы передачи файлов
на ПК и CasaOS отключены, их порты 18566/18567 закрыты.

## Резервные копии и откат

Приватная папка установки: `/home/cl0rex1/quiby-releases/1.1.1`, режим 700.
Рабочий API использует образ `quiby-core-api:1.1.1` и исходный Compose
`/home/cl0rex1/quiby.core/deploy/casaos/docker-compose.yml` вместе с
`/home/cl0rex1/quiby-releases/1.1.1/api.override.json`. Данные API остаются
в прежней папке. `api.rollback.json` сохраняет прежний образ и окружение;
`api-before.json` — снимок контейнера. Эти файлы содержат секреты.

- Онлайн-копия API: `data/backups/pre-111-20261021T224953Z.sqlite`
  в существующей папке данных API.
- Полная офлайн-копия Minecraft:
  `/crafty/backups/quiby-pre-625-20261021T225109Z.tar.gz` внутри Crafty.
  В ней сохранён прежний Quiby 1.1.17, мир, настройки и приватное окружение.
- Отчёт: `deployment-report.json`, проверка direct: `direct-verified.ok`
  в приватной папке установки.
- Маркер Minecraft: `quiby-update-625.ok` в папке сервера
  `/crafty/servers/827910b5-67f5-459f-8e6d-8b8e4b34367b`.

Обновление прошло через объявленный `quiby restart 60` и одноразовый hook,
сохраняющий watcher Crafty. После первого запуска обнаружены старые файлы
`config-templates`, принадлежавшие root: шаблоны повторно скопированы,
владение шаблонов и управляемых скриптов приведено к пользователю игры
1000. Все установленные моды проверены; обычный `start.sh` восстановлен.
Расписание 06:59 → не раньше 07:01 и 20:00 по Астане сохранено.

Для отката API используйте исходный Compose с `api.rollback.json` вместо
рабочего override. Возвращать SQLite или архив мира можно только после
остановки соответствующей службы и отдельного сохранения новых данных.
Откат мира потеряет прогресс после создания копии, если его не сохранить.

Для отключения direct очистите его настройку API и пересоздайте API с
обновлённым override, затем остановите provider и координатор. Обычный
маршрут Minecraft от этих служб не зависит. Не восстанавливайте старую
базу ради одного отключения direct.

Длительная нагрузочная проверка и повторный внешний замер Кирова не
выполнялись. Старые сообщения Sable о восстановлении bounds и прежний
SIGSEGV Ubuntu Java не считаются исправленными этим выпуском.
