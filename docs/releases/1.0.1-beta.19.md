# quiby.core Тестовый 1.0.1-beta.19

- Правка sekyk: контроль папки mods продолжается после проверки, во время запуска Java и игры. Неподтверждённый или изменённый JAR останавливает процесс Minecraft с причиной в уведомлении. Файлы не удаляются. Решения вайтлиста фиксированы на текущий запуск.
- Наблюдение за файловыми событиями дополнено сверкой хешей каждые 30 секунд; оно освобождается после завершения игры.
- Все изменения beta.18 сохранены: проверка и заявки ресурспаков, устранение гостевой смены скина, категории/логотипы модов, выделение контента и подписи скинов.
- Обновления лаунчера обязательны: перед запуском проверяется GitHub, доступная новая версия блокирует игру до установки. API отклоняет запуск стандартных старых лаунчеров без поддерживаемой версии; минимум 1.0.1-beta.19. Сбой связи не отменяет требование.

Сборка остаётся 6.1.17, Quiby 1.1.12. API для ресурспаков уже обновлён на домашнем сервере. Minecraft-сервер обновлять не требуется. Это клиентская проверка, а не гарантия защиты от произвольно изменённого клиента.
