# quiby.core 1.0.1-beta.23

- Плавное появление и скрытие панели выбранных файлов, раскрытие журнала запуска, новостей и дополнительных параметров Java. Стрелки и подписи показывают, что блок можно раскрыть.
- Переключатель уменьшения движения, единые состояния кнопок, заглушки иконок и индикаторы ожидания API.
- Пять понятных фильтров модов; неизвестные и требующие проверки файлы объединены в «Другое».
- Заявки отправляются в фоне. Единая карточка показывает отправку, доставку, рассмотрение и решение, поднимается при изменении статуса. Добавлены повторная отправка и восстановление после прерывания.
- Гардероб блокирует изменение скина во время запуска и работы Minecraft.
- Исправлены гонки импорта, обработки скинов и скриншотов, сохранение настроек, проверка загрузок, доступность диалогов и контраст уведомлений.
- Панель администратора и API поддерживают создание, редактирование, закрепление и рассылку новостей в лаунчер. Для новых функций требуется обновлённый API.

## Сборка 6.1.20 / Quiby 1.1.15

Семь недостающих рецептов Create Radars, исправленные названия модов и цепная детонация разрывных снарядов Create Big Cannons. Штатные взрывы учитывают укрытия; число подрывов за тик ограничено.

Проверки: 63 успешных автоматических теста (одна проверка symlink пропущена Windows), 39 UI-тестов, TypeScript и запуск собранного Electron. Рецепты и воздушная цепная реакция проверены на отдельном сервере NeoForge с CBC и Radars.

Minecraft 1.21.1 / NeoForge 21.1.250 / Java 21. Windows-установщик предварительного канала не подписан.
