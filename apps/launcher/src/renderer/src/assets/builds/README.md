# Скриншоты сборок

Положите реальные изображения в подкаталоги `visual/`, `standard/`, `draft/`.
Поддерживаются .png, .jpg, .jpeg, .webp; порядок — по имени файла (01, 02, …).
Vite включит их в просмотр сборки при следующей сборке. Пока файлов нет, интерфейс показывает честное пустое состояние.
Visual / Standard / Draft — профили одной серверной сборки; состав серверного манифеста общий.
