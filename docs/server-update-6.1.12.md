# Обновление Minecraft-сервера до 6.1.12 (тестовая)

Minecraft 1.21.1 / NeoForge 21.1.250. Обновление существующего сервера.
В отличие от 6.1.11, требуется новый Quiby 1.1.9: порог урона добавлен в код мода.
API, Docker, Cloudflare и приложение лаунчера обновлять не требуется.

1. Остановите Minecraft-сервер. Сохраните резервную копию мира, mods и конфигов.
2. Переместите старый quiby-*.jar в резервную папку вне mods. Установите
   mods/quiby-1.21.1-1.1.9.jar из архива. Не оставляйте две версии Quiby в mods.
   Off Balance остаётся 2.0; если он уже установлен, заменять его не нужно.
   Sable и Sable Player Ragdoll 0.7.5 оставьте. Старые Revival/Reactions/Corpse не возвращайте.
3. В config/offbalance-server.toml установите значения ниже в существующих секциях.
   Сохраните остальные настройки.

```toml
[balance]
balanceEnabled = false

[hurtProxy]
hurtProxyEnabled = true
hurtProxyMobsTarget = true

[manualDismount]
dismountRequireGrounded = true
dismountMaxSpeed = 2.5
dismountMaxSpin = 3.5
dismountHoldTicks = 3
```

4. В config/quiby-server.toml задайте:

```toml
[ragdoll]
onDamage = true
minDamage = 4.0
onExplosion = true
cooldownTicks = 20
```

5. Если существуют аналогичные файлы в <level-name>/serverconfig/, измените те же
   параметры и там. Имя мира указано в server.properties. defaultconfigs содержит
   шаблоны для новых миров. Копирование шаблонов не меняет настройки существующего мира.
6. Запустите сервер. Игрокам обновить сборку через лаунчер до 6.1.12.

4 единицы урона — 2 сердца за один удар после снижения урона защитой.
Мелкие повреждения не суммируются для запуска ragdoll. Реакция на область взрыва
остаётся независимой и может срабатывать без потери двух сердец.
Вставание требует 3 тика устойчивых условий (0.15 секунды при 20 TPS).

Проверьте: небольшой урон от падения не включает ragdoll; удар от 4 единиц включает;
вставание при лёгком движении стало проще; мобы выбирают тело целью. Сборка и проверки
границ порога проходят, но эти игровые сценарии нужно подтвердить на сервере.

Откат: остановить сервер и восстановить весь комплект резервной копии, включая мир.
