# Установка 6.1.27 — 22.10.2026

[Сборка и серверный ZIP опубликованы](https://github.com/cl0rex1/quiby-modpacks/releases/tag/v6.1.27).
Quiby 1.1.20 установлен на существующем Minecraft Crafty. API активировал
манифест 6.1.27. Лаунчер/API остаются 1.1.1, бот и маршруты сети не менялись.
Исходники: core `2e24985`, mod `53d7fcc`.

Штатный `quiby restart 60` объявил остановку игрокам. Одноразовый hook
сделал офлайн-копию и применил проверенный серверный комплект. Обычный
`start.sh` восстановлен из нового комплекта, watcher Crafty сохранён.

- Резервная копия внутри Crafty:
  `/crafty/backups/quiby-pre-627-20261022T074551Z.tar.gz` (режим 600).
- Папка Minecraft:
  `/crafty/servers/827910b5-67f5-459f-8e6d-8b8e4b34367b`.
- Маркер установки: `quiby-update-627.ok`, предыдущий стартовый скрипт:
  `start.pre-627.sh`, комплект: `.quiby-release-6.1.27` в папке Minecraft.
- Приватные отчёты и установщик домашнего сервера:
  `/home/cl0rex1/quiby-releases/6.1.27` (`deploy.log`, `verified.json`).

После установки повторно проверены все 37 SHA256 серверных модов. Свежий
журнал новее маркера установки, содержит Quiby 1.1.20 и успешный `Done`.
Ошибок применения mixin и обработчиков очистки Quiby в нём нет. Публичный
Minecraft status подтверждает online, лимит 25; API отдаёт сборку 6.1.27.
Первичная проверка установщика могла увидеть `Done` старого журнала до
старта JVM, поэтому она дополнена отдельной проверкой свежести журнала
и версии мода после запуска (`verified.json`).

Gradle и регрессионные проверки прошли. Изолированный dedicated-тест
проверил наступивший срок очистки и повторное планирование на 15 минут,
сохранность лута, исключение оффлайн/защищённых/посторонних тел, вход при
недоступном UUID-индексе, чтение сохранённой очереди и удаление шести частей.
Длительное ожидание интервала в тесте заменено установкой наступившего срока.
На рабочем сервере тестовые тела не создавались и очистка принудительно
не запускалась; таймер начинает очередной 15-минутный период после запуска.

Очередь хранится в `quiby_retired_ragdolls.dat` каждого измерения. Её нельзя
очищать вместе с кэшем: там могут оставаться запросы для выгруженных частей.
Тела без сохранённой привязки, потерянной ещё до фикса, не выбираются по
скину или нику. Ограничение и поведение описаны в [заметках выпуска](6.1.27.md).

Для отката сначала остановите Minecraft, сохраните новый прогресс и только
затем восстанавливайте приватную резервную копию. Возврат всего мира без
сохранения новых данных потеряет прогресс после 07:45:51 UTC.
