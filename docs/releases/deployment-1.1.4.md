# Развёртывание 1.1.4 — 23 октября 2026

Опубликован Windows-лаунчер 1.1.4. Исходный отчёт игрока содержал `reason=error`, `stage=frpc`; пользователь подтвердил отсутствие EXE. Старый отчёт не сохранил точный текст ошибки загрузки/подготовки, поэтому конкретный сетевой или файловый отказ не установлен.

Встроенный frpc 0.71.1 извлечён из фактического NSIS-установщика и проверен по закреплённому SHA-256 вместе с наличием LICENSE/NOTICE. При запуске проверяется тот же хэш, отдельной сетевой загрузки у игрока больше нет. Сборка проверяет ресурс до упаковки и после неё; сторонний EXE исключён из повторной подписи, чтобы контрольная сумма не менялась.

Проверки: 77 тестов прошли, 1 тест симлинков пропущен из-за ограничений Windows; отдельно пройдена интеграция с настоящими frpc/frps, TLS и API-авторизацией; TypeScript и Electron smoke прошли. С бинарным файлом именно из NSIS, пустым кэшем и рабочим API direct выбрался автоматически: медианы 3 мс против 231 мс обычным маршрутом, контрольный Minecraft ping/pong 3.55 мс. Это проверка с данного ПК, а не подтверждение NAT у удалённого игрока.

API 1.1.4 проверен в отдельном контейнере без сети и активирован после публикации установщика. Создана резервная копия SQLite. Переменные окружения, тома, порты и настройки доступа сохранены; обязательная версия лаунчера 1.1.4, прежняя 1.1.3 получает HTTP 426. Сборка остаётся 6.1.34, quiby.mod 1.1.27; Minecraft этим обновлением не перезапускался.

Публичные latest/beta-метаданные и все четыре актива Windows проверены по размерам/хэшам. Arch 1.1.4 собран локально; `.PKGINFO` проверен, SHA-256 пакета `0a8270e281b7728fa38164d764e6fbd697e0590b9832d66e5caf2df926f2f8d0`. Linux-артефакты не публиковались.
