Тестовый выпуск quiby.core для Windows x64.

- Уведомления сохраняются между запусками; из сообщения «Сбой Minecraft» можно сохранить полный приложенный лог.
- Скриншоты: выбор нескольких файлов, копирование, перемещение в корзину и инструменты в просмотре.
- Шейдеры и схематики: групповое выделение и удаление в корзину.
- Сборка 6.1.6: Off Balance 2.0 вместо Ragdoll Revival, Reactions и Corpse. Реакции на урон и взрывы реализованы в Quiby 1.1.4; Active Balance выключен.
- Семь рецептов Create Radars, исправленные переводы Radars и Storage, компактный процент заполнения ящика.
- Анимация логотипа на раннем экране NeoForge и внутри Minecraft во время загрузки ресурсов. Сохранены настоящие индикаторы прогресса.
- Исправление скина физического ragdoll-тела включено в Quiby 1.1.4. Поведение тел и мобов необходимо перепроверить в совместной игре.

Проверено: сборка мода и установщика, 26 успешных автоматических тестов (ещё один пропущен), запуск Standard на Java 21, вход в отдельный тестовый мир и загрузка новых рецептов. В стороннем Create Deco остаётся ошибка рецепта `createdeco:placard`, не связанная с новыми рецептами.

Minecraft-сервер нужно обновить архивом из релиза сборки 6.1.6. API и Cloudflare Tunnel для этих изменений обновлять не требуется.

Установщик: `quiby.core-Setup-1.0.1-beta.11.exe`. Канал автообновления — beta. Установщик пока не подписан.
