# Выпуск 24.10.2026: лаунчер/API 1.1.6, сборка 6.1.39, мод 1.1.32

Опубликованы стабильные релизы Windows-лаунчера и сборки:

- https://github.com/cl0rex1/quiby-launcher-releases/releases/tag/v1.1.6
- https://github.com/cl0rex1/quiby-modpacks/releases/tag/v6.1.39

Проверены публичный манифест, контрольные суммы новых JAR, серверного архива,
API и установочных скриптов, а также SHA-512 установщика в latest.yml / beta.yml.
Linux/Arch не публиковался.

Перед установкой API прошёл отдельную проверку с изолированными сетью и SQLite.
Рабочему Minecraft отправлена команда `quiby restart 15`. Замена файлов
разрешилась только после завершения старого JVM и нового подтверждения
`All dimensions are saved` в журнале после команды перезапуска. Создана
резервная копия остановленного мира, конфигурации и модов.

После установки проверены SHA-256 всех 37 серверных модов, открытый JAR
quiby.mod 1.1.32 внутри нового JVM и успешная загрузка Minecraft. API 1.1.6
активирован с сохранением прежнего окружения и политики доступа. Публичный
API подтвердил сборку 6.1.39, мод 1.1.32 и доступность Minecraft; лаунчер 1.1.5
получает 426. Проброс UDP голосового чата сохранён.

Проверки кандидата: 81 тест Node прошёл, один тест пропущен; проверка настоящего
frpc с задержанным Login; два UI-теста раздела сети; Electron smoke;
Gradle build/check. На окончательном JAR отдельно пройдены обе фазы радиации
с полноценным перезапуском JVM, ванильный эффект ветрового заряда и разделение
Sable при удалении владельца. Последний сценарий воспроизводит исходную ошибку
на quiby.mod 1.1.31 и завершается успешно на 1.1.32.

Уменьшение пинга внешних игроков этим выпуском ещё не подтверждено.
Проверка: обновить лаунчер, полностью перезапустить Minecraft, получить новый
отчёт через **Настройки → Сеть → Копировать отчёт**. RTT старого и нового
лаунчеров напрямую не сравнивается: старый включал установление соединения.
