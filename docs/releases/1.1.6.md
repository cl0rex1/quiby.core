# quiby.core 1.1.6

- Исправлена преждевременная отмена direct при медленном запуске frpc: лаунчер дожидается ответа туннеля и повторяет попытки в пределах времени проверки. Обычный маршрут, Relay, Direct QUIC и Direct KCP сравниваются по пяти замерам; неустойчивое соединение не выбирается.
- Исправлен расчёт RTT: время установки соединения и получения статуса Minecraft больше не прибавляется к пингу.
- В **Настройки → Сеть** добавлены проверка маршрутов без запуска Minecraft, задержка и разброс замеров, время проверки, версия лаунчера и копирование отчёта. Причины отказа сохраняются отдельно для каждого маршрута, без билетов авторизации. Проверка недоступна во время игры.

Сборка Minecraft **6.1.39**, quiby.mod **1.1.32**:

- Исправлено падение Sable при попытке разделить физическую конструкцию, уже удалённую взрывом или обработчиком разделения. Разделение существующих конструкций сохранено.
- Радиация аварии Create Nuclear распространяется в радиусе **135–900 блоков**, в зависимости от реактора. Мощность разрушительного взрыва не менялась. Заражение обрабатывается постепенно и сохраняется после перезапуска; удалённые чанки ради него не загружаются.
- Эффект зелья ветрового заряда сохраняет ванильное поведение без дополнительного взрыва, звука и разрушения от Explosion Overhaul.

Для проверки пинга установите 1.1.6, полностью перезапустите Minecraft и отправьте отчёт из **Настройки → Сеть → Копировать отчёт**. Прохождение NAT и снижение задержки у внешних игроков ещё требуют проверки из их сетей. В игре доступна команда `/ping`.

Windows-установщик опубликован. Linux/Arch в этот выпуск не публикуется; direct на Linux пока не включён.
