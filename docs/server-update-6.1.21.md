# Серверное обновление 6.1.21

Quiby 1.1.16 исправляет перехват разрывных пушечных снарядов зенитными:
взрыватели CBC и Create: Radars теперь распознают их как цели. Штатный взрыв
flak больше не вызывает повторную детонацию того же снаряда через цепную реакцию.

Остановите Minecraft-сервер и сделайте резервную копию мира. Замените предыдущий
игровой Quiby JAR на `mods/quiby-1.21.1-1.1.16.jar`, не оставляя две версии.
Архив обновления предназначен для сборки 6.1.20. Мир и настройки не заменяются.
Для старых сборок используйте полный серверный архив и его инструкцию.
Клиентский `quiby-early-loading` на dedicated server не устанавливается.

Клиенты получают сборку 6.1.21 через обновление модпака в лаунчере beta.23.
Обновление API само по себе не устанавливает мод на Minecraft-сервер.
Для автоматического выбора радаром включите подходящий фильтр целей Projectile
и используйте бесконтактный взрыватель. Условия взведения сохраняются.

Проверено на отдельном игровом сервере: настоящие взрыватели CBC и Radars
подрывают flak около летящего HE, затем HE детонирует ровно один раз.
Проверены цепочка, укрытия, дальность, исключение болванок, самого перехватчика
и временно защищённых при выходе из ствола целей.
