# quiby.core 1.1.7

- Добавлена **предустановка Minecraft**: скачивание Java 21, Minecraft, NeoForge и файлов выбранной сборки без запуска игры. Предустановка доступна при закрытом запуске Minecraft; по завершении файлы проверяются, а лаунчер сообщает о готовности.
- В админке **Игроки → Запуск Minecraft** можно отдельно закрыть запуск игры, задать сообщение, разрешить исключения и установить личный запрет игроку. Доступ к лаунчеру настраивается независимо.
- Лаунчер показывает сообщение о закрытом запуске и позволяет проверить доступ снова. При открытии доступа уже загруженные файлы используются повторно.

Чтобы подготовиться к сезону: войдите через Discord, выберите Standard или Draft и нажмите **«Предустановить Minecraft»**. Игра автоматически не запустится. Когда администрация откроет доступ, станет доступна кнопка запуска.

Сборка Minecraft остаётся **6.1.40**, quiby.mod **1.1.33**. Установщик Windows; Linux/Arch в этом выпуске не публикуется.
