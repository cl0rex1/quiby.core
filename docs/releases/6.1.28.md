# Сборка 6.1.28 · Quiby 1.1.21

Исправлены независимая блокировка ПКМ из Sable Ragdolls Patch при исчезновении тела и перепутанные поля освещения/overlay у спрайтов REI 16. Логотип использует сглаживание текстуры. Скрыты `explosionoverhaul:vinlanx_the_light` и его пустая творческая вкладка; зарегистрированный предмет сохранён для совместимости миров.

Клиент quiby.mod при загрузке проверяет игровой билет через API, соответствие аккаунта и владение временным Ed25519-ключом лаунчера. Dedicated-серверу билет не нужен. Обычная проверка при входе на сервер сохранена. Изменённый сторонними лицами JAR технически может обойти клиентскую проверку; серверная проверка остаётся границей доступа.

Для оператора (уровень прав 2), в нужном измерении:

```
/quiby opening prepare <x> <y> <z>
/quiby opening status
/quiby opening start
/quiby opening cancel
```

Подготовка принимает координаты существующего загруженного костра. Запуск даёт отсчёт 10 секунд в onbar, затем 20 секунд вспышек и звуков на расстоянии 4–7 блоков. Эффекты не создают настоящие взрывы, не меняют блоки и не наносят урон. Факт открытия сохраняется в мире; после открытия повторный запуск запрещён. Команды на рабочем сервере автоматически не выполняются.

Голосовой адрес закреплён как `play.quiby.me:24454`, включая при подключении к игре через локальный direct-порт. Рабочему контейнеру нужен опубликованный UDP 24454, VPS — DNAT/SNAT и разрешение только этого UDP-маршрута через WireGuard. Скрипт `deploy/minecraft/voicechat-vps.sh` делает резервную копию правил перед настройкой.
