# Серверное обновление 6.1.19 — подготовлено, не опубликовано

Create Radars заменён на приложенную версию `5.0-EA-3.0.0-1.21.1`.
Quiby 1.1.14 удаляет семь наших дополнительных рецептов Radars и содержит
перевод всех 242 ключей новой версии. Подготовлены необязательные обработчики
публичных событий сети радара и целеуказания для будущего дополнения;
новое игровое поведение пока не включено.

Клиент и Minecraft-сервер должны получить одинаковую новую версию Radars.
Для существующего сервера: остановить процесс, сохранить резервную копию мира,
убрать прежние JAR Create Radars и Quiby, установить новые JAR из архива.
Не оставлять одновременно две версии одного мода.

API и бот также потребуют обновления для исправлений доставки заявок.
Файл по-прежнему передаётся вложением Discord через временную очередь в памяти
API; ошибку одного вложения бот обрабатывает отдельно от других заявок.
Принятая заявка и подтверждённая доставка различаются в интерфейсе.

Этот выпуск не опубликован. Журнал проверок и ограничений:
`docs/patches-2026-10-09.md`.
