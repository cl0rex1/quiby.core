# quiby.core Тестовый 1.0.1-beta.20

Обновление интерфейса контента по четырём обращениям sekyk и toshhii. Сборка Minecraft остаётся 6.1.17; обновлять API, бота и Minecraft-сервер для этих изменений не требуется.

- Плитки и список во всех пяти категориях контента; выбранный вид сохраняется отдельно для каждой категории.
- Единые поиск, счётчики, кнопки и панели групповых действий, включая ресурспаки. Панели центрируются в библиотеке, с учётом сайдбара. Добавление файла стоит перед открытием папки.
- Выбор всех видимых файлов работает по текущему фильтру и сохраняет скрытое выделение. Частичное удаление модов корректно сохраняет оставшиеся записи при ошибке.
- Списки растягиваются по высоте окна; убраны постоянный нижний отступ, пути и цитаты под библиотеками. Компактная шапка для невысокого окна и аккуратная прокрутка.
- Ресурспаки показываются после локального чтения папки, до завершения сетевой проверки. Добавлен поиск; фоновые проверки ограничены четырьмя одновременными запросами. Неизменившиеся хеши и данные отображения повторно используются; решения допуска запрашиваются заново.
- Миниатюры скриншотов загружаются группами по четыре и повторно используются до изменения файла. Общая панель выделения совместима с просмотром, копированием и корзиной.
- Гардероб прокручивается до всех плащей. Названия убраны с миниатюр и остаются у выбранного персонажа.
- Переименованный скин сразу получает новую подпись на главном экране и экране запущенной игры. Исходное имя файла и синхронизация текстуры сохраняются.
- Для ресурспаков исправлены термины формы заявки, подсказки, ссылка Modrinth и уведомление. Имена ZIP больше не подменяются распознавателем модов.

Проверены типы всех workspace, production build и полный набор тестов: 46 успешно, один прежний пропуск. UI проверен на тестовых данных в окнах 1037×609 и 1037×900, включая сетевую задержку 3 секунды, выбор по фильтру, инструменты снимков, подпись скина и конец гардероба. Реальная доставка заявки ботом этим прогоном не проверялась.

Кеши применяются только для отображения; контроль модов и ресурспаков перед запуском и во время игры сохранён. Установщик Windows x64; тестовая версия, подпись кода пока отсутствует.

Упаковка лаунчера не пересобирает нативные зависимости: его runtime-зависимости работают на JavaScript, а необязательный register-scheme исключён из установщика. Discord RPC внутри Electron использует app.setAsDefaultProtocolClient вместо этого нативного fallback. Настройки сборки SQLite для API не изменялись.
