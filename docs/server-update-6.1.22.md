# Серверное обновление 6.1.22

В Visual, Standard, Draft и серверный состав добавлен **Create Nuclear 2.0.0**.
**Create: Radars** обновлён с **5.0-EA-3.0.0** до **5.0-EA-3.1.4**.
Minecraft 1.21.1, NeoForge 21.1.250, Create 6.0.10, CBC 5.11.7 и Quiby 1.1.16.

Для сервера на 6.1.21:

1. Остановите сервер и сохраните резервную копию мира.
2. Удалите `mods/create_radar-5.0-EA-3.0.0-1.21.1.jar` и другие старые версии этого мода.
3. Скопируйте содержимое `quiby-server-update-6.1.22.zip` в корень сервера.
   В `mods` должны находиться единственные версии:
   `create_radar-5.0-EA-3.1.4-1.21.1.jar` и `createnuclear-2.0.0-neoforge.jar`.
4. Запустите сервер. Клиентам также нужна сборка 6.1.22.

Архив обновления содержит актуальные Quiby 1.1.16, Off Balance и настройки
предыдущей версии. Для более старых серверов используйте полный
`quiby-server-6.1.22.zip` и его инструкцию. Пользовательские миры в архивы не входят.

Сборка архивов из корня репозитория:

```powershell
node scripts/build-server-update.mjs
npm run pack:server
```

## Проверка совместимости

Проверены SHA-256 всех файлов манифеста и 37 серверных JAR, наличие обоих
модов во всех трёх профилях и зависимости сервера. NeoForge 21.1.250 / Java 21
дошёл до готовности и штатно остановился в отдельном тестовом мире.

На настоящем сервере повторно прошёл тест Quiby: загружены семь рецептов
Radars, проверены перехват HE-снарядов взрывателями Radars и CBC,
однократная цепная детонация и исключения для укрытий и безопасных целей.

В исходном Radars 3.1.4 остаются ошибки рецептов
`create_radar:crafting/radar_jammer` и
`create_radar:crafting/radar_warning_reciever`.
Рабочие альтернативные рецепты Quiby для постановщика помех и приёмника
загрузились и проверены тестом. Исходные пользовательские JAR сохранены без изменений.
