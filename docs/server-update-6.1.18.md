# Серверное обновление 6.1.18 — подготовлено, не опубликовано

Quiby 1.1.13 исправляет возврат к offline-рэгдоллу на выделенном сервере,
автоматически загружает/строит индекс Explosion Overhaul и проверяет вход
по игровому билету аккаунта и подписи временного ключа лаунчера.

**До установки обновите API, лаунчер и клиентский Quiby вместе.** Старый клиент
не поддерживает проверку входа и будет отклонён. Нужны новые API-маршруты
`/api/game/join-ticket` и `/api/game/verify-join-ticket`. Публикация клиентского
манифеста 6.1.18 должна включать новый Quiby JAR. Git pull сам по себе не доставит
игнорируемые бинарные артефакты и не обновит установленные лаунчеры.

Для новой установки используйте полный серверный архив
`temp/quiby-server-6.1.18.zip` и [инструкцию Ubuntu/CasaOS](../deploy/minecraft/README.md).
Он содержит 36 JAR, серверные/common конфиги, автоматическое применение
необходимых параметров с резервными копиями и установщик NeoForge.

Старый `scripts/build-server-update.mjs` создаёт только **дельту**: Quiby,
Off Balance и три шаблона настроек. Для существующего сервера остановите процесс,
сохраните резервную копию мира, замените старый Quiby JAR новой версией и внесите
значения из шаблонов в текущие `config` и `<level-name>/serverconfig` с сохранением
прочих параметров. Не оставляйте два Quiby JAR одновременно.

Новый `quiby-access-server.toml` создаётся модом с `enabled=true` и
`apiUrl="https://api.quiby.me"`. С нашим Discord-входом нужен `online-mode=false`;
доступ проверяется по аккаунтам API. Если раньше был включён ванильный whitelist,
либо перенесите разрешённых игроков в него, либо используйте только обязательную
проверку Quiby, как в полном серверном архиве. Не отключайте проверку Quiby на
сервере с offline-входом.

Рэгдолл: `minDamage=9.0`, `minDismountTicks=20`, hurt proxy включён,
`balanceEnabled=false`, `recoveryGateEnabled=false`,
`dismountRequireGrounded=true`. Кластеризация взрывов отключена.

Проверены Java 21 dedicated server до `Done`, ответ на игровом порту,
инициализация рэгдолла, автоматическое сканирование Explosion Overhaul и
штатная остановка. Подписи/билеты проверены автоматическими тестами; вход
реального игрока и Linux/Docker требуют проверки после совместного обновления.
