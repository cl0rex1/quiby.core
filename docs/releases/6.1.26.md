# Сборка 6.1.26 — экран перезапуска

Quiby обновлён до 1.1.19. Исправлено открытие экрана ожидания сервера:
рабочий сервер присылал `multiplayer.disconnect.generic` («Отключение»),
а клиент принимал только другие причины разрыва соединения.

Экран появляется после ранее объявленного `/quiby restart`, ждёт указанное
время и доступность Minecraft, затем подключается снова. Обычный выход,
отказ авторизации и бан не заменяются экраном перезапуска.

Регрессионная проверка использует сетевое отключение игрока с настоящей
выгрузкой мира вместо одного ручного открытия экрана. Протокол состояния
сервера не изменён: клиентский фикс совместим с сервером Quiby 1.1.18.

Отдельно подготовлены локальные Linux x64 пакеты лаунчера 1.1.1: Debian
`.deb` и переносимый `.tar.gz`. Они не входят в GitHub Releases. Linux
использует обычный публичный Minecraft-маршрут; автоматический direct
и автообновление лаунчера в этой версии доступны на Windows.
