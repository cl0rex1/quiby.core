# quiby.core 1.0.0 — первый релиз

В этот релиз вошли все изменения интерфейса, контента, гардероба, настроек, почты и просмотра скриншотов.

- Подключение к `play.quiby.me:25565` и сборка 6.1.23. Доступны Standard и Draft; пользователи Visual выбирают сборку заново.
- Свои GIF/изображения на главной и в гардеробе, а также режим без фона. Оригинальное качество файлов сохраняется.
- Удобный просмотр скриншотов с масштабированием, перемещением, сбросом и подтверждением копирования внутри окна.
- Новости с Markdown, изображениями, видео, обложками и карточками ссылок; редактор и предпросмотр в панели управления.
- Общий переключатель доступа к лаунчеру для всех игроков с сообщением и автоматическим восстановлением интерфейса после открытия. Настройка сохраняется в базе и записывается в журнал.
- **Наигранное время хранится в аккаунте на API** и восстанавливается после переустановки. Существующее локальное время переносится один раз; повторные запросы, потеря сети и несколько устройств не удваивают минуты. Уже запущенная игра сохраняет время и при закрытом доступе к лаунчеру.
- API принимает актуальный релиз 1.0.0. Предыдущие выпуски лаунчера сняты с публикации.

Из тестовых 1.0.1/1.0.2 установите 1.0.0 вручную поверх прежней версии: автоматическое обновление на меньший номер не предлагается. Настройки и коллекции сохраняются.
