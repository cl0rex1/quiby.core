# quiby.core 1.1.3

- Direct повторяет попытки создания туннеля через NAT с интервалом 5 секунд и ждёт до 35 секунд. Единичный таймаут STUN больше не заканчивает проверку до следующей попытки. При неудаче сохраняются короткие диагностические сообщения без билетов, затем используется обычный маршрут.

Автоматический direct в текущем лаунчере реализован для Windows. Linux использует обычный адрес сервера.
- Сборка 6.1.29 / Quiby 1.1.22: новое главное меню и пауза, логотип слева, статус сервера и число игроков справа, название сезона «Взрыв - это искусство.» снизу. Исправлено смешивание прозрачности логотипа.
- Выбор Г/Л — только левой кнопкой мыши. Enter отправляет сообщение, `!текст` отправляет глобально; команды `/g` и `/l` убраны.
- Церемония открытия: настраиваемый worldborder, Adventure и защита участников; отдельный запуск с фейерверками и безопасными снарядами CBC. При открытии — граница 20000, Survival и очистка эффектов.
- Ручной и вечерний перезапуски запускают сервер не раньше чем через 30 секунд. Утреннее окно 06:59–07:01 по Астане сохранено.

Minecraft 1.21.1 / NeoForge 21.1.250. Для церемонии: `/quiby opening prepare <x> <y> <z> [диаметр]`, затем `/quiby opening start`. По умолчанию диаметр 64 блока, допустимый диапазон 16–20000. Костёр должен быть в обычном мире. `/quiby opening cancel` отменяет подготовку с восстановлением прежних настроек; после открытия останавливает оставшиеся эффекты. `/quiby opening status` показывает состояние.

Установщик Windows публикуется. Linux/Arch остаётся отдельным локальным пакетом.
