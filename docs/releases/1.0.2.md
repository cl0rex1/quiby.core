# quiby.core 1.0.2

В панели управления появился раздел **«Доступ к лаунчеру»**: общий переключатель для всех игроков и сообщение о закрытии.

- Закрытие действует на вход через Discord, существующие сессии и выдачу разрешений на запуск игры. Исключений для отдельных аккаунтов нет.
- Открытые лаунчеры показывают экран блокировки в течение 30 секунд или при возврате в окно. Новые входы и запуски блокируются сразу на API.
- После открытия доступа интерфейс восстанавливается автоматически, сохранённая сессия остаётся на месте.
- Настройка хранится в базе и сохраняется после перезапуска API. Изменения записываются в журнал действий; управлять доступом может только администратор.
- Панель управления и обновления лаунчера остаются доступны. Уже запущенная игра продолжает работать.

По умолчанию доступ открыт. Для этой функции требуется лаунчер **1.0.2** или новее; обновление доступно из beta и стабильного канала.
