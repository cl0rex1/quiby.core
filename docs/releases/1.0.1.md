# quiby.core 1.0.1 — первый стабильный релиз

- Автоматическое подключение к `play.quiby.me:25565`; сборка 6.1.23 совместима с сервером 6.1.22.
- Visual временно закрыта. При переходе с Visual лаунчер предлагает выбрать Standard или Draft.
- Личные GIF и изображения для главной страницы и гардероба; каждый фон можно полностью отключить в «Настройки → Интерфейс».
- Исходный фон главной отображается качественным кадром сборки. Личные GIF сохраняются без перекодирования; режим уменьшенного движения использует неподвижный кадр.
- В просмотрщике скриншотов — иконка сброса масштаба и подтверждение копирования прямо над изображением.
- Новости поддерживают Markdown, изображения, MP4/WebM, YouTube и Vimeo, таблицы, цитаты и карточки ссылок. В панели управления появились форматирование, обложка и предпросмотр.
- API принимает только стабильные версии лаунчера от 1.0.1. Beta-версии обновляются до релиза через прежний канал обновлений.
- Убрана кнопка «Меньше движения» из стартового экрана. Настройка остаётся в интерфейсе.

Установите поверх предыдущей версии: настройки, сессия и коллекция сохраняются.
