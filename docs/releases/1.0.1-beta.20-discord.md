**Тестовое обновление quiby — 1.0.1-beta.20**
Сборка Minecraft: **6.1.17**

**Совместные правки sekyk и toshhii**
• Добавлены «Плитки / Список» во всех вкладках контента. Вид сохраняется отдельно для каждой категории.
• Объединены кнопки, счётчики и выделение файлов. Панели действий больше не съезжают относительно сайдбара; у ресурспаков тоже появилась панель.
• «Выбрать все» учитывает текущий фильтр и сохраняет выделение скрытых файлов.
• Добавлен поиск ресурспаков. Список появляется без ожидания сетевой проверки и сохраняется при возврате во вкладку.
• Контейнеры растягиваются с окном. Убраны лишний отступ снизу, пути и цитаты; улучшена прокрутка.
• Гардероб прокручивается до всех плащей. Названия убраны с миниатюр скинов и остаются у выбранного персонажа.
• Оптимизирована подгрузка миниатюр скриншотов и проверка списка ресурспаков.

**Правка toshhii**
• После переименования скина новая подпись сразу появляется на главном экране и экране запущенной игры.

**Правка sekyk**
• Исправлены слова «мод» в форме заявки на ресурспак, подсказки, ссылка и уведомление об отправке.

**Учтено 4 обращения от 2 тестеров; совместные обращения посчитаны по одному разу.**
Обновлять сервер, API и бота для этих правок не нужно.
