# quiby.core Тестовый 1.0.1-beta.16

- Добавлена заметная плашка «Доступ к лаунчеру закрыт» и отключение запуска игры для заблокированного аккаунта.
- Статус доступа обновляется автоматически каждые 30 секунд и при возвращении в окно. Блокировка при запуске отображается сразу.
- Ручное одобрение Gamma/Fullbright по SHA-1 теперь разрешает конкретный JAR. Новая версия файла требует отдельного решения.
- Усилено обнаружение Gamma/Fullbright: варианты написания, Unicode-экранирование, внутренние пути и признаки gamma-mixin-классов.
- В серверной панели добавлена кнопка «Загрузить JAR»: название и SHA-1 определяются в браузере, сам файл на сервер не отправляется.

Для новых правил проверки требуется актуальный API quiby.core. Minecraft-сервер и сборку модов обновлять не нужно.
