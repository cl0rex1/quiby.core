# Сборка 6.1.32 · Quiby 1.1.25

В последние три секунды отсчёта из центра костра вылетает снаряд CBC. Он раскрывается в воздухе на кольцо из 16 снарядов трёх типов — фугасных, дымовых и шрапнельных — с восемью дополнительными фейерверками. На высоте около 60–64 блоков и радиусе 28 блоков кольцо одновременно взрывается с центральной вспышкой, облаками дыма CBC, искрами и одним общим звуковым ударом. Затем продолжается основной салют с увеличенным разлётом. Урона, опасной шрапнели и разрушений нет, отмена останавливает все стадии.

Включены исправления 6.1.31: заметные воздушные взрывы и звук, разлёт снарядов по дугам, фейерверки на четыре блока выше, озвученный десятисекундный отсчёт и сохранение режима/собственных эффектов операторов уровня 2 и выше.

Проверки: Gradle; отдельный dedicated server с реальными CBC/Sable и сетевыми пакетами; настоящий клиент с проверкой 16 моделей, дыма, взрывных частиц, общего звука и десяти сигналов. Лаунчер и API остаются 1.1.3.
