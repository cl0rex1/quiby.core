# Веб-панель quiby

Адрес: https://api.quiby.me/admin/ — тот же API-контейнер, порт 3001 и существующий Cloudflare Tunnel. Дополнительный контейнер и DNS-запись не требуются.

Вход: значение ADMIN_API_KEY из deploy/casaos/.env. Не публикуйте ключ и не добавляйте его в URL. Он используется только при входе; браузер получает HttpOnly/SameSite=Strict cookie на 2 часа. В production cookie передаётся только через HTTPS. Смена ADMIN_API_KEY отзывает ранее выданные сессии панели. Секреты остаются в существующем .env.

Возможности:
- Список заявок на моды, поиск, фильтр статусов и страницы. Одобрение, отклонение, отзыв решения с причиной.
- Ручной допуск/запрет конкретного SHA-1 файла.
- Аккаунты игроков: Discord ID, ник, UUID, даты входа, разрешение и закрытие доступа.
- Рассмотрение заявок на смену ника через существующий сервис. При одобрении изменяется UUID; данные мира по старому UUID автоматически не переносятся.
- Журнал изменений, выполненных через панель, и сводка активной сборки.

Закрытие доступа применяется при следующей серверной проверке сессии или запуске; уже подключённый клиент автоматически не отключается. Удаления аккаунтов и мира в панели нет. Журнал панели не включает действия старых API-эндпоинтов или бота. Ручной допуск не отменяет запрет gamma/fullbright в лаунчере.

Обновление на Ubuntu:
```bash
cd ~/quiby.core
git pull --ff-only
cd deploy/casaos
docker compose up -d --build api
docker compose ps
docker compose logs --tail=50 api
curl -I https://api.quiby.me/admin/
```

Сделайте резервную копию каталога deploy/casaos/data перед обновлением. Миграция добавляет таблицу admin_audit, не меняя существующие аккаунты и решения. Лаунчер, Minecraft-сервер и бот ради панели обновлять не нужно.
