# quiby. s6

Текущий тестовый манифест — 6.1.3, Minecraft 1.21.1 / NeoForge 21.1.250. Исходная сборка импортирована как 6.1.0.

Во все три профиля добавлен `quiby.mod` 1.1.1. Клиентская часть мода запрашивает скины игроков из `https://api.quiby.me/api/skins/{USERNAME}.png` и использует обычный скин Minecraft при отсутствии Quiby-скина. Выбранный скин хранится в API и доступен другим игрокам сборки. `CustomSkinLoader` удалён из манифеста; лаунчер удаляет старый JAR при синхронизации.

| Сборка | Исходная папка | Модов |
| --- | --- | --- |
| Visual | mods | 63 |
| Standard | mods-Standard | 51 |
| Draft | mods-Draft | 29 |

Манифест содержит общий каталог с принадлежностью файлов к профилям. Лаунчер выбирает состав перед синхронизацией; устаревшие официальные моды удаляются при переключении. Пользовательские одобренные моды обрабатываются отдельно.

Перенесены config, defaultconfigs, kubejs (если есть), оба ресурспака FreshAnimations и FA+Player, options.txt. Из шейдеров оставлен только ComplementaryUnbound_r5.9.3.zip для Visual. В исходнике Iris отключает шейдеры (`enableShaders=false`); это сохранено. Порядок включения ресурспаков сохранён.

Explosion Overhaul: исходные параметры REALISTIC_2 / QUALITY_64 и `firstLaunchComplete=true`, конфиг синхронизируется при каждом запуске. Остальные конфиги и options.txt устанавливаются только при отсутствии, чтобы сохранять настройки игрока. Личные миры, серверы, скриншоты, логи, кэш, резервные копии, избранное REI и история не переносятся. Из options.txt исключены последний сервер и параметры конкретного окна/аудиоустройства.

Повторный импорт из корня репозитория:

```powershell
npm run pack:import -- 'C:\Users\cl0rex1\AppData\Roaming\ModrinthApp\profiles\quiby. s6' 21.1.250 6.1.0
```

Команда копирует файлы в локальное хранилище API и активирует манифест в SQLite. Исходный профиль не изменяется. Двоичные файлы находятся в `apps/server/storage/files/imported/` (исключены из Git); манифест хранится рядом с этим README. Для другого сервера необходимо перенести это хранилище и опубликовать манифест через административный API. Один Git-клон не содержит модов. Адрес игрового сервера задаётся через MC_SERVER_IP, из личного профиля он не импортируется.

## Неопубликованные правки тестеров

Обращения и статусы: [журнал тестеров](../../docs/tester-feedback.md).
В `overrides/config/explosionoverhaul/ExplosionSourceBlacklist.json` подготовлены исключения `VANILLA` для зарядов ветра игрока и бриза. Импорт сборки накладывает эти значения поверх исходного файла, сохраняя остальные исключения. Это предотвращает запуск эффектов Explosion Overhaul для этих двух источников; физика обычного заряда ветра сохраняется.

В тестовом манифесте 6.1.3 опубликованы overrides и новый JAR quiby.mod с переводами. На игровом сервере с Explosion Overhaul требуется такое же исключение: решение о рассылке эффекта принимает сервер. В одиночной игре используется конфигурация клиента со встроенным сервером.
