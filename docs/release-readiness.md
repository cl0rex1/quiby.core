# Подготовка публичного запуска — 26 сентября 2026

Текущая сборка подходит для локальной проверки и закрытой беты. Публичное развёртывание ещё не выполнено.

## Выполнено и проверено

- NeoForge 21.1.250: создан обязательный launcher_profiles.json, используется реальный профиль neoforge-21.1.250, проверяются установленные библиотеки. Ошибки установщика сохраняются в temp/neoforge-21.1.250-install.log папки игры.
- Выбирается Java 21 вместо несовместимого системного Java 25. Исправлен конфликт vanilla client.jar с обработанным NeoForge Minecraft. Visual фактически дошла до главного меню, после проверки тестовый процесс был остановлен.
- Библиотеки Mojang отбираются по ОС и архитектуре. Ошибки загрузки ресурсов больше не скрываются.
- JWT сессии Discord/API больше не передаётся в аргументах Minecraft. Полноценная Microsoft/Minecraft-аутентификация этим не реализована.
- Копирование сообщения показывает временный toast без добавления в почту. Карточки модов используют метаданные JAR, ленивую загрузку иконок и замену при ошибке; кэш Modrinth сохраняет URL иконки и проекта.
- В текущий манифест импортированы 52 встроенных иконки и 27 ссылок на проекты из 63 модов. Для остальных используются известные метаданные или поиск проекта.
- Исправлены относительные пути assets для file://, порядок регистрации IPC заставки и переход к основному окну. Иконка PNG включена в ресурсы и настройки Windows EXE/NSIS.
- Electron 44.4.5, electron-builder 26.15.3, Vite 6.4.3, SQLite 6.0.1, adm-zip 0.6.1. npm audit: 0 известных уязвимостей на момент проверки.
- npm run build проходит; npm test: 16 успешных тестов верхнего уровня, 1 пропуск проверки symlink из-за ограничений Windows. Остальные проверки локальных файлов выполняются. Тесты modSafetyService переведены на временную SQLite вместо рабочей базы.
- Windows NSIS собирается; упакованное приложение открывает интерфейс без dev-сервера. Установщик не подписан (Authenticode: NotSigned).

## Что остаётся перед публичным релизом

1. Развернуть API по постоянному HTTPS-адресу и собрать клиент с VITE_QUIBY_API_URL. Сейчас без переменной используется localhost:3001; текущий установщик — локальный проверочный артефакт.
2. Настроить production Discord OAuth redirect URL, серверные секреты и общий ключ bot API. Проверить реальный вход, членство, привязку ника и решение заявки через работающий Discord-бот. Локальные API-тесты не заменяют эту проверку.
3. Проверить аутентификацию непосредственно на Minecraft-сервере: привязка Discord в API не защищает сама по себе от подключения с чужим ником. Для online-mode необходима полноценная Microsoft/Minecraft-сессия. Текущий клиент не получает такую сессию.
4. Автоматически доставлять проверенный Java 21 runtime или явно включить его установку в подготовку компьютера. Сейчас Java 21 должна уже присутствовать. Проверить чистую Windows без Java/Modrinth и без предыдущих Minecraft-файлов.
5. Подписать Windows-установщик и проверить установку обновления на чистой машине. Проверка GitHub Releases и загрузка обновления подключены в beta-версии, но установщик пока не подписан.
6. Для обновлений сборки добавить подписанные манифесты, staging всей версии и переключение после полной проверки, восстановление после прерывания, retry/timeouts и проверку хешей всех Minecraft/NeoForge-зависимостей. Текущий downloader уже проверяет SHA-256 файлов сборки и скачивает через .part, но обновление всей сборки не транзакционное.
7. Проверить Standard/Draft, смену профиля туда-обратно, повторный запуск, вход на реальный сервер и обновление предыдущей версии на нескольких чистых машинах. Фактический запуск игры в этой работе проверен для Visual на текущем компьютере.
8. Резервировать SQLite и объекты сборки; включить healthcheck/журналы сервера. Проверить права на распространение модов и ресурспаков перед публикацией собственного зеркала.

## Доставка сборок

Файлы модпака и beta-установщик теперь опубликованы в двух публичных GitHub Releases, при этом исходный репозиторий остаётся приватным. Скрипт проверяет SHA-256 локальных файлов, загружает их в черновик и публикует его после манифеста. Клиент скачивает только изменившиеся файлы. Порядок работы и ссылки: [github-releases.md](github-releases.md).

Для будущего роста можно перенести объекты в Cloudflare R2 с CDN. Бесплатный тариф сейчас покрывает 10 ГБ хранения, но требует контроля операций и собственного домена для рабочего CDN: https://developers.cloudflare.com/r2/pricing/ .

