# quiby.core 1.1.5

- Лаунчер сравнивает обычное подключение, зашифрованный relay и два вида прямого соединения — QUIC и KCP. Проверки идут параллельно. Используется маршрут с меньшей задержкой, прошедший проверку стабильности. Relay больше не может выдаваться за direct: у каждого отдельный локальный порт. В диагностике сохраняются все замеры и журнал NAT без билета входа. Успех NAT у внешнего игрока требует проверки из его сети.
- Исправлены исходные настройки Simple Voice Chat: голос больше не отключён и значки соединения видны. Старый ошибочный набор настроек исправляется один раз с резервной копией; последующее ручное отключение сохраняется. При первом исправленном запуске предлагается настройка микрофона.
- Аватары Minecraft-сообщений в Discord получают версию по содержимому скина, поэтому новые сообщения используют актуальный скин.
- Добавлены синхронизация эмодзи сервера Discord и подсказки `:имя:` в игре. Анимированные эмодзи представлены статическим кадром.
- Упоминания определяются по игровому нику. Для неизвестной привязки появляется объяснение; локальный чат сообщает, что пинг в Discord требует глобального сообщения (`!текст`). Локальные сообщения остаются только в игре и админском Discord-канале.

Сборка Minecraft **6.1.36**, quiby.mod **1.1.29**:

- Добавлены рецепты Farmer’s Delight для котла и разделочной доски в REI.
- Операторская панель `/quiby admin` доступна также из меню паузы. Онлайн-игроки, телепортация, призыв, здоровье, режим игры, просмотр инвентаря без перемещения предметов и перезапуск с подтверждением. Сервер проверяет права.
- За границей проверяются все части рэгдолла; операторы также ограничены границей, наблюдатели исключены.
- После выхода в креативе проверяется наличие записи оффлайн-тела; ограниченное повторное создание использует штатное восстановление Off Balance и не дублирует запись/инвентарь.
- Музыка открытия использует общую громкость, независимо от фоновой музыки и пластинок. Оператор может проверить её без запуска церемонии: `/quiby opening music`, остановить — `/quiby opening music stop`.
- Старый клиент после перезапуска сервера должен полностью закрыть Minecraft, обновить сборку в лаунчере и запуститься заново: устаревшая версия мода не допускается.

Windows-установщик публикуется. Linux/Arch остаётся локальным пакетом; direct на Linux пока не включён.
