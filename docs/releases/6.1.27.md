# Сборка 6.1.27 — очистка тел

Quiby 1.1.20 исправляет удаление оффлайн-тела после входа владельца.
Запросы на удаление головы и всех частей теперь сохраняются в данных мира.
Отсутствующий в загруженных чанках объект не считается удалённым: очередь
дождётся его загрузки и переживёт штатный перезапуск сервера. Подтверждение
принимается только для удаления Sable с причиной `REMOVED`, а не `UNLOADED`.
При запуске также подхватывается оставшаяся очередь Off Balance.

Каждые 15 минут реального времени с момента запуска сервера удаляются
зарегистрированные трупы умерших игроков. Оффлайн-тела, активные рэгдоллы,
защищённые тела и посторонние физические объекты не выбираются для очистки.
Вещи из удаляемого трупа выпадают через штатное действие Off Balance.
Недоступное измерение пропускается вместе с его инвентарём.

Проверено на отдельном dedicated Minecraft с настоящими Off Balance и Sable:
планировщик, шесть частей тела, раздельная обработка оффлайн/защищённых/
посторонних тел, сохранность лута, вход при недоступном UUID-индексе,
сохранение/чтение очереди и однократное восстановление инвентаря.

Исправление необходимо установить на сервер. Идентификация тел основана
на точных ID из сохранённых записей Off Balance; неизвестные объекты,
уже потерявшие привязку до установки фикса, по внешнему виду не удаляются.
